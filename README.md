#  Personal Portfolio Website

A modern and responsive portfolio website built using HTML, CSS to showcase my skills, projects, and contact information.

##  Features

- Responsive Design
- Modern User Interface
- About Section
- Skills Section
- Projects Showcase
- Contact Form
- Resume Download
- GitHub & LinkedIn Integration
- Smooth Scrolling Navigation

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
